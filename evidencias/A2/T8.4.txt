OBSERVAÇÕES:
X-Powered-By = ausente (helmet remove na API :3000).
ACHADO: o frontend (nginx :5173) expõe o cabeçalho "Server: nginx/1.31.0" (Troca 2), revelando o software do servidor e sua versão exata - disclosure de tecnologia de baixa severidade (server_tokens on).
ATENÇÃO (não é vulnerabilidade): o GET http://localhost:5173/.env retornou HTTP 200, mas o corpo é o index.html da SPA (fallback try_files .../index.html do nginx), NÃO o conteúdo do arquivo .env. O arquivo .env não é exposto.
/api/debug e /api/api-docs na API retornam 404 (rota não encontrada).
